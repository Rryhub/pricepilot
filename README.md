# PricePilot

A responsive landing page and interactive price-comparison product demo for premium-headphone shoppers.

## Pages

- `index.html`: Landing page with an interactive exact-model matching example.
- `demo.html`: Product-link form and illustrative three-retailer cost comparison.

## Run locally

From this directory, run `python3 -m http.server 8000`, then open http://localhost:8000.

No build step or dependencies are required. Fonts load from Google Fonts.

## Demo scope

Retailer prices and savings are illustrative. Live browsing, retailer verification, destination-specific checkout costs, billing, and wallet buy calls are not connected. The form does not save or submit product links. No paid-use or repeat-use claims are made.
